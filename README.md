# Activity AI — Personal Activity Tracking AI

Milestone 1 foundation for a local-first Android + Windows personal activity intelligence system.

Current scope: Level-1 usage telemetry, normalized sessions, privacy policies, local databases, daily/weekly reporting, diagnostics, and Android debug APK CI.

The first device-test build intentionally does **not** include location collection, Accessibility Service observation, screen capture, Snapchat visual capture, or message/content collection.
